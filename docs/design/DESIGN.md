# 聚合argb驱动桌面界面

界面采用 AntdUI 2.4.12（Apache-2.0），运行于现有 .NET 8 WinForms。交互组件由库绘制；监控、USB、配置和开机自启继续复用现有实现。

## 参考与功能分区

水冷页参考 ASUS InfoHub 1.0.7：左侧屏幕预览，右侧显示内容和监控项目，底部媒体缩略图。主导航提供水冷屏幕、主板灯光、机箱屏幕、共享监控。裁剪、动画片段、布局、时钟、媒体排序、灯效参数均保留独立编辑入口。媒体支持图片、GIF 和 MP4。原厂三套背景从本机安装目录导入配置目录，不改变已选择的媒体。

## 颜色

深色桌面主题：背景 #0D1117；区域 #151C25；输入 #1D2733；分隔 #2A3849；正文 #EDF2F7；次要文字 #9CACBD；强调 #5AD5C7；强调悬浮 #81E4D9；选中底色 #1C3A3C；错误 #F28B82。媒体与屏幕画布使用其配置颜色，不受界面主题影响。卡片使用 12 点圆角及细边框，选中导航同时显示强调边框和文字。

## 字体与尺寸

中文使用本机 Microsoft YaHei UI；字号为正文 10、说明 9、分区 12、页面标题 16、产品名称 18 点。数字监控使用 Segoe UI。控件高度 36，主要动作 40；间距采用 4、8、12、16、24。窗口逻辑尺寸 1180 × 640，最小 980 × 580，并随实际 Windows DPI 缩放。

## 布局与滚动

顶部产品栏、设备导航和底部保存栏固定。水冷页预览保持正方形，右侧设置区域单独垂直滚动，媒体条只横向滚动。其他页的设置区独立垂直滚动。模态编辑器保留固定保存和取消按钮，属性区域独立滚动，不将操作按钮推到窗口外。

## 组件

按钮、选择器、数字输入、开关、颜色选择器和区域面板使用 AntdUI 原生组件。复用统一字段行、区域标题、操作栏和表单框架。媒体缩略图来自用户所选原文件，不以静态截图代替界面。布局画布保留真实拖动、尺寸调整和键盘微调。

高级设置沿用双栏模态表单：左右属性区域独立滚动，底部错误提示、取消和保存固定。字段标签宽度 180 点，正文、控件高度及间距复用现有尺度；模态窗口逻辑尺寸 920×610、最小 800×540。数字、枚举、开关、文字和传感器选择使用共享 OptionsForm 字段构造方法，修改仅保留在草稿，验证成功后返回主窗口，再由“保存并应用”提交后台。字体文件和背景映射使用有明确添加、移除和命名操作的列表编辑器。

视频适配器列表来自 DXGI 的实际硬件设备，以厂商、设备和子系统编号持久化选择。设备名称显示在选择器中；已保存但未连接的适配器显示明确状态，硬件模式不会默默换到另一块显卡。字体列表显示文件名，完整路径通过提示查看。背景管理按钮允许换行，避免高 DPI 下横向截断。

## 状态与数据

打开界面加载现有配置，保存应用整份设置；取消编辑丢弃该编辑器的修改。选中导航和媒体使用底色与文字变化。错误显示在当前界面。媒体、布局、温度单位变化更新草稿预览，预览使用后台共享采样。关闭窗口后退出配置进程并释放界面定时器、画布和缩略图；独立后台继续运行。配置读取失败时报告错误并停止启动，避免使用默认配置接管设备。

## 可访问性与性能

主窗口预览复用输出位图，离开水冷页时释放预览解码器和位图；打开布局、裁剪或媒体库窗口时释放主预览解码器，保留静态画面，关闭编辑窗口后恢复预览。媒体库排序与移除复用未变的卡片和缩略图。

保留 Windows 标题栏、窗口调整、键盘焦点和明确的字段标签。GIF 与视频仅在可见的预览及设备输出时刷新，遵守帧率上限；无装饰性常驻动画。MP4 通过已有 NAudio 接口调用 Windows Media Foundation，解码帧直接按行复制到当前位图，不保留中间整帧数组，不启动播放器进程；裁剪源画面与结果预览复用同一个解码器和源帧。缩略图直接从当前解码帧生成，主窗口和媒体库卡片支持键盘选择。采用系统动画偏好控制组件的交互动画。此界面为原生 Windows 程序，浏览器、手机及 Lighthouse 指标不适用。
